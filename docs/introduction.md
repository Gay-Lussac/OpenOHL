# OLS CAD

**OLS CAD — Open Line System Computer Assisted Design** is an open-source, modular platform for the design and analysis of overhead power lines: terrain and LiDAR, conductor sag-tension and finite-element wire systems, loads and structure checks, clearances, thermal rating, spotting, drawings and more — from a desktop application, a command-line tool or Python, alone or several people on one project.

This book contains:

- the **user guide** — how to use the tools;
- the **theory manual** — the engineering behind every calculation, with references;
- the **design documents** — goals, architecture, roadmap and architecture decisions;
- the **development guide** — validation cases, plugins, performance rules and the desktop app's conventions;
- the **validation report** — every calculation compared against published reference results.

The API reference of the Rust crates is generated by `cargo doc`.

> OLS CAD is pre-alpha. Engineering results must always be verified by a qualified engineer.
