# OHL-Design UI review: windows opened from the menus (2026-10-27)

The owner asked (2026-10-27) for one design for the check windows — some
could be sent to a panel, others were panels already —, for more room in
them (lists that can be made taller, longer scrolling rather than
cramming), and for a clearance result to show the weather case that led
to it, as the distance between conductors under unequal wind does. This
page is the survey made before the change: what each window was, how it
docked, where it was cramped, and what was proposed. The decisions taken
are in the [decision log](decisions.md) (2026-10-27); the user guide says
how it works now. Built, in active development, not approved yet.

## How windows were shown (before)

Three kinds, side by side:

1. **Dock pages** (`app::Tab`, drawn by the dock's `TabViewer` in
   `app/viewer.rs`): a tab of the main window with a tab bar; it can be
   dragged into another group or out into a dock window of its own, and
   moved by the tab's context menu (left, right, a window).
   *Distance between conductors*, *under unequal wind* and *Performed
   checks* opened as such pages in a floating dock window first
   (`open_page`, group 5, 1050 × 780 px); *Structure loads* opened as a
   page beside the 3D view; the *Clearances* page is a View page on the
   left. To the user these look like panels already.
2. **Dockable tool windows** (`dockable::show`, `dockable.rs`): an
   `egui::Window` with a small **📌 Dock as a panel** button in its title
   bar; docked, its content is drawn into a `Tab::Tool(Panel)` tab
   (**⬈ Float** brings it back); remembered docked for the session. Used
   by *Vertical* and *Radial clearances*, *Vegetation*, *Display weather
   cases*, the editor windows, *New structure from a template*, *Replace
   structure*, *Measurements*, *Follow and snap*.
3. **Plain floating windows** (`egui::Window`): everything else, among the
   checks *Thermal rating*, *Line parameters*, *Galloping ellipses*, *Wire
   tensions*, *String checks*, *Internal clearances*, *Safety volumes*,
   *As-built wires*, and *Bill of materials*, *Spot structures*, all
   settings windows.

Every check window already ends with the shared Run footer
(`check_help::body`/`footer`/`run_button`): the body scrolls as a whole
above the footer, so a long window scrolls rather than grows off screen.
What was cramped is inside the body: nested lists of a fixed height
(`ScrollArea::max_height`) and tables with 2–4 px between rows. The body
used egui's default item spacing (8 × 3 px).

Other observations:

- The 📌 button sits in the title bar, so a window that cannot dock has an
  identical title bar without it: the difference between kinds 2 and 3
  was invisible until hovered.
- Kind 1 pages close with their tab's ×; kind 2 and 3 windows close with
  the window's ×; a docked kind 2 closes with its tab's × (the tool
  closes): the same gesture in each place.
- *Distance between conductors* switched the weather case shown for the
  whole line to the clicked result's case (and back when its page
  closed); under unequal wind it drew the two conductors at their winds
  as an overlay, the case shown kept. The ground clearance windows only
  went to the span: the span stayed in the case shown, which is often not
  the case of the finding.
- The overlay labels of a measured pair are in a dark box; the standing
  rule for view notes is the object's colour without a box. The new
  result-case note follows the rule (in its wire's display colour since
  the owner's answer, 2026-10-27; it was white at first); the older
  labels are left as they are (a separate change).

## Chosen design

See the decision log, 2026-10-27, *Check windows: one design*:
every check and result window opened from the menus is a dockable tool
window (kind 2), through one helper, `check_help::window`, which also
sets the shared spacing; lists in them use `check_help::list` (a drag
handle under the list sets its height, remembered for the session).

The owner's answers (2026-10-27) to the points left open — every check
and result window the same, Spot structures and the Clearances page
included, resizable lists in the settings windows that can grow, the
result note in its wire's colour — are in the decision log, *Check
windows: the owner's answers*; the status column above says what is
built.
